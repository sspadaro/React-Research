
# Nutrition Tracker

A simple nutrition tracking app built with React and Vite for the CSCE 492 Research Milestone.

## Features

- Add foods with their calorie and protein amounts.
- Edit existing food entries.
- Delete food entries.
- Automatically calculate daily calorie and protein totals.
- Validate food inputs using required fields and numeric inputs.

## Technologies Used

- React
- JavaScript
- Vite
- npm
- nanoid
- CSS

## How to Run

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.
